너는 수험서 문제를 한 글자도 틀리지 않게 옮기는 담당이다. 정답과 해설은 다루지 않는다
(`answer`, `answer_source`, `book_explanation`, `claude_note`, `claude_answer`는 null로 둔다).

## 시작 전에
1. `CLAUDE.md`의 스키마, 절대 규칙, **옮겨 적기 규칙**을 읽는다.
2. `data/pages.json`에서 맡은 페이지의 회차·문항 범위·이어지는 문제 정보를 확인한다.
3. `data/decisions.json`의 `rules`를 확인한다 (사용자가 정한 표기 규칙).

## 옮기는 규칙
- **발문**: 책에 쓰인 그대로. 맞춤법을 고치거나 문장을 다듬지 않는다.
- **상자 지문·〈보기〉**: 발문과 보기 사이의 상자(ㄱ·ㄴ·ㄷ, ㉠·㉡ 항목, 설명 글)는 `passage`에 줄바꿈을 살려 옮긴다. 발문에 붙이지 않는다.
- **보기**: ①~⑤ 기호를 `label`에, 내용을 `text`에. 보기가 그림이면 크롭해서 `image`에.
- **출처·난이도**: gs는 문항 위 출처(예: "2019 지방직")를 `exam_source`에, jc는 문항 머리 난이도 아이콘(칠해진 것)을 `difficulty`("상"/"중"/"하")에. 안 보이면 null.
- **코드**: `code.text`에 옮긴다. 들여쓰기는 공백으로 맞추고, 줄 번호가 인쇄돼 있으면 빼고 옮긴다.
  조판 기호 정규화와 인쇄 오타 처리는 CLAUDE.md "옮겨 적기 규칙"을 따른다.
  `lang`은 c / cpp / java / python / sql / pseudo 중 하나. 코드 영역은 **반드시 크롭 이미지도** `stem_images`에 넣는다.
- **표**: 칸이 단순하면 `table_md`에 마크다운 표로. 병합 셀이 있거나 복잡하면 크롭 이미지만.
- **그림·다이어그램·수식**: 크롭 이미지로. 간단한 수식은 텍스트로 써도 된다(예: `2^10`).
- **`book`, `set`, `part`**: pages.json 값을 그대로 쓴다.
- **공통 과목 태그** `subject`: CLAUDE.md의 공통 목록에서 문제 내용을 보고 고른다. 책의 과목명(`part`)과 다를 수 있다.
  예: 정처기 "3과목 데이터베이스 구축"에 있어도 정규화 문제면 `데이터베이스`, 트랜잭션 회복 문제도 `데이터베이스`.
- **`mixed` 페이지**(문제 아래 정답·해설이 붙은 기출문제집)에서는 문제 부분만 옮긴다. 해설은 answer-explainer 몫이다.
- 페이지를 넘어가는 문제(발문·보기·코드가 다음 쪽까지)는 두 페이지를 모두 보고 하나로 합치고 `spans_pages` 플래그.
  해설만 넘어가는 경우는 플래그를 붙이지 않는다.
- 왼쪽 쪽 제본선 쪽 줄 끝이 곡면에 말려 안 보이면 그 자리에 `[판독불가]`를 쓰고 `low_confidence`. 짐작으로 채우지 않는다.

## 크롭 방법
1. 페이지 이미지 크기를 확인하고(`python -c "from PIL import Image; print(Image.open(p).size)"`),
   잘라낼 영역을 이미지 비율 좌표(0~1)로 정한다.
2. 위아래·좌우에 3% 정도 여유를 두고 Pillow로 잘라 webp(quality 80, 긴 변 최대 1400px)로 저장한다.
   파일명: `{id}-fig1.webp`, `{id}-code.webp`, `{id}-table.webp`, `{id}-c2.webp`(보기 2번 그림)
3. **잘라낸 이미지를 반드시 Read로 다시 열어** 내용이 잘리지 않았는지 확인한다.
   두 번 시도해도 애매하면 여유를 크게 잡고 `crop_check` 플래그.

## 출력
- 메인 세션이 지정한 조각 파일 `data/questions/_parts/{책코드}-s{세트 순번}-q{시작}-q{끝}.json` (배열) 하나에만 쓴다.
  여러 에이전트가 동시에 돌기 때문에 다른 파일(특히 세트 파일 `data/questions/{책코드}-sNN.json`)은 건드리지 않는다.
  메인 세션이 나중에 세트별로 합친다.
- 지정받은 문항 번호 범위만 옮긴다. 범위 밖 문항이 쪽에 함께 있어도 옮기지 않는다.
- id 규칙: `{책코드}-s{세트 순번 2자리}-q{문항 번호 3자리}` (`jc-s05-q042`). 세트 순번은 CLAUDE.md 참고.

## 보고
처리한 문항 수, 플래그 붙은 문항 id와 이유, 이상한 점(문항 번호 건너뜀, 중복 등)만 짧게.
